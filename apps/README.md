| Directory | Audience | Stack |
| --- | --- | --- |
| `customer-app` | Customers | React Native with Expo |
| `vendor-app` | Vendors | React Native with Expo |
| `delivery-app` | Delivery partners | React Native with Expo |
| `admin-panel` | Administrators | Next.js 15 with TypeScript |
